# 👕 Camisas Interclasse 2025

Sistema de pedidos de camisas para o Interclasse do 3º Ano EM.

---

## 🚀 Como rodar o localhost (modo desenvolvimento)

### 1. Abra o terminal na pasta do projeto

No VSCode: `Ctrl + '` (acento grave) ou clique com o botão direito na pasta e selecione **"Abrir no Terminal"**.

### 2. Instale as dependências (só precisa fazer uma vez)

```bash
npm install
```

### 3. Ligue o servidor local

```bash
npm run dev
```

### 4. Acesse no navegador

Abra: **http://localhost:5173**

> O número da porta pode variar. Olhe o terminal — vai aparecer algo como:
> `➜  Local: http://localhost:5173/`

---

## 📦 Outros comandos

| Comando | O que faz |
|---|---|
| `npm run dev` | Liga o servidor local (modo desenvolvimento) |
| `npm run build` | Gera a versão final para produção |
| `npm run deploy` | Faz build e publica no GitHub Pages |
